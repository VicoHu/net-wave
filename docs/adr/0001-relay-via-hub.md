# MVP 传输采用服务中心中转而非 WebRTC 直连

net-wave 的原始诉求是局域网"P2P 传输"，但我们决定 MVP 中所有消息与文件（文本、图片、文件）统一经服务中心中转，浏览器之间不做 WebRTC DataChannel 直连：中转实现简单可靠，天然支持离线消息与历史回看，且千兆局域网下绝对速度足够（约 60MB/s 量级）。代价是中心设备网卡收发各一遍，大文件传输速度约为直连的一半。WebRTC 直连作为二期方案记录于根目录 TODOS.md。

## Considered Options

- **WebRTC DataChannel 直连**：不占用中心网卡、无中转带宽损耗；但需要信令/ICE/消息分片（单条 ≤256KB）/背压流控，复杂度高，浏览器兼容性问题多，历史消息需另建通道。
- **中心中转（选定）**。
