# M1 手动验收清单

覆盖 spec（Issue #1）User Stories 1–18。逐项在真实环境执行并勾选。

环境：`pnpm dev`（或 `npm start`）启动服务中心；PC 浏览器 + 手机（同一局域网）。

> 标记说明：✅ 已由自动化测试或桌面浏览器实测验证；☐ 需真实设备人工执行。
> 全部通过即 M1 收官（Issue #7 / T6）。

## 部署者

- [x] **1. 一条命令启动服务中心** ✅ `pnpm dev` / `npm start` 后浏览器打开即见应用（health 测试覆盖启动就绪）
- [x] **2. 首页展示局域网地址与二维码** ✅ 头部「扫码加入」弹窗含二维码与可复制地址（center-info API + 浏览器实测）
- [x] **15. 服务中心自动发现局域网地址** ✅ 无需手动查 IP（API 返回首个非内部 IPv4）

## 节点身份（US 3–5）

- [x] **3. 进入即自动获得随机昵称** ✅ 「形容词+名词」式昵称自动分配（presence 测试 + 浏览器实测）
- [x] **4. 昵称可修改** ✅ 头部铅笔按钮改名，全中心实时生效（presence 测试覆盖改名广播）
- [x] **5. 身份被浏览器记住** ✅ 刷新 / 重进无需重设（httpOnly cookie；离线补投递测试覆盖重连识别）

## 在线与私聊（US 6–8）

- [x] **6. 实时在线节点列表** ✅ 上线/下线即时反映（presence 测试覆盖双向感知）
- [x] **7. 与任一节点开启私聊** ✅ 在线节点列表点「发起私聊」即建会话（chat 测试覆盖）
- [x] **8. 互发文本实时到达** ✅ WS message 双端推送（chat 测试覆盖）

## 图片与文件（US 9–11，需真实手机重点复核）

- [x] **9. 图片内联缩略图 + 点击大图** ✅ 桌面浏览器实测（缩略图 + 预览缩放）；☐ 手机端点击大图与横竖屏表现
- [x] **10. 任意类型文件以卡片呈现（名称/大小）** ✅ 桌面浏览器实测；☐ 手机端长卡片折行表现
- [x] **11. 上传/下载实时进度** ✅ 附件区上传进度圈 + 文件卡片下载百分比（桌面实测 64MB 流式 sha256 一致）；☐ 手机端大文件进度体验
- [ ] **14. 历史消息中的文件可重新下载** ✅ 重启后下载字节一致（files 测试覆盖）；☐ 手机端重新下载

## 持久化与离线（US 12–13）

- [x] **12. 消息按时间序持久保存，重启后回看完整** ✅ chat/files/rooms 测试均含重启断言
- [x] **13. 离线消息上线后自动出现** ✅ 离线补投递测试覆盖（conversations-updated + 重新拉取）

## 布局与提醒（US 16–18）

- [x] **16. PC 双栏 / 移动端单栏自适应** ✅ 桌面 1280px 双栏实测；单栏切换为 URL 驱动（`/?c=<id>`，支持浏览器返回键）；☐ 手机 / 平板真实宽度走查（375 / 768 / 1024）
- [x] **17. 验证码消息复制辅助** ✅ 4–8 位数字消息带「复制」按钮，secure context 一键复制（桌面实测）；☐ 手机非 secure context 下自动全选降级
- [ ] **18. 新消息页内提醒（标题闪烁）** ✅ 逻辑已实现（页面隐藏时收到他人消息 → 标题每秒交替「【新消息】net-wave」，回页恢复）；☐ 需真实场景验证：手机停留在其他标签页/后台时观察标题

## 收官前必做的真实设备项（合并执行一次）

1. 手机扫首页二维码 → 进入应用 → 出现随机昵称 → 改名（US 2/3/4/15）
2. PC 与手机互发：文本（含验证码，测复制）、截图（缩略图 + 大图）、一个 >10MB 文件（进度）（US 8–11/17）
3. 手机切到其他标签页，PC 发消息 → 手机标签标题闪烁；回到页面后停止（US 18）
4. 重启服务中心（Ctrl+C 后重新 `pnpm dev`）→ 手机刷新后历史完整、文件可重新下载（US 12/13/14）
5. 375px 宽度走查单栏布局：会话列表 ↔ 聊天窗切换、浏览器返回键（US 16）

全部勾选后，在 Issue #7 勾掉对应验收项并关闭。
